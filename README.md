# Microeconomics 3 Knowledge Atlas

An English-language, interactive study map for Microeconomics 3. Open `index.html` in a browser, or serve this directory with any static HTTP server. The deployed site uses only HTML, CSS and JavaScript; KaTeX and the web fonts load from public CDNs.

## Use

- Drag the map to pan; scroll or use the controls to zoom. **Fit graph** restores the overview.
- Click a concept to see intuition, essential equations, notation, a mathematically drawn diagram, a worked application, and directed links to related topics.
- Search by concept name or explanation, and filter by chapter. Press `/` to focus search and `Esc` to close a card.
- The arrow direction indicates a conceptual dependency or next step, not causality.

## Source method

Content and examples were checked against the course PDFs supplied for this project. Cards cite filenames and PDF page numbers for their worked applications. The lecture PDFs inform the theory and figure types. Numerical illustrations generated from a lecture formula are labelled as illustrations in the card. The original PDFs are **not** included in this public repository.

## Scope and caveats

The graph has 35 concept cards and 55 directed relationships. It emphasizes material relevant to rapid midterm review. The diagrams are generated from explicit functions in `app.js`, so they stay sharp at any screen size. They are teaching diagrams; the card text gives the exact exercise numbers where applicable. Source references are filenames and PDF pages because the course files themselves are not redistributed.
